## Changes

- Outward App теперь оформлен как единый Windows-клиент для локальных proxy-сессий: темный PySide6-интерфейс, список профилей, статус подключения, время сессии, локальные HTTP/SOCKS5 адреса и консольный лог sing-box собраны в одном окне.
- Добавлены профили VLESS Reality, Shadowsocks и WireGuard с проверкой пользовательской конфигурации, отображением типа подключения, сервера, SNI и страны профиля.
- Приложение генерирует конфигурацию sing-box под выбранный профиль, поднимает HTTP и SOCKS5 proxy на `127.0.0.1`, поддерживает пользовательские DNS-серверы и автоматически подбирает свободные порты рядом с заданными значениями.
- Дефолтные локальные proxy-порты для новых настроек перенесены на `27182` и `27183`, чтобы реже пересекаться с другими локальными сервисами.
- Добавлен запуск выбранных ресурсов через Google Chrome или Microsoft Edge с отдельным браузерным профилем, SOCKS5 proxy, нормализацией URL и опциональным отключением расширений.
- Список ресурсов запуска вынесен в отдельное управление: можно добавлять, редактировать и удалять адреса, а нейтральный ресурс по умолчанию заменен на `example.com`.
- Добавлен тумблер автоподключения при запуске: приложение может зарегистрироваться в автозагрузке Windows и после старта подключаться к выбранному профилю.
- Настройки клиента разделены по вкладкам: лог консоли, параметры подключения и отдельная вкладка `Обновление` для проверки версии, фоновой загрузки установщика и запуска обновления.
- Добавлены фоновая проверка GitHub Releases, загрузка установщика в `%LOCALAPPDATA%\OutwardApp\updates`, проверка SHA256 при наличии контрольной суммы и silent-установка обновления из приложения.
- Повторный запуск Outward App теперь разворачивает уже запущенное окно из трея вместо открытия второго экземпляра приложения.
- Управление sing-box стало аккуратнее: Outward App хранит сведения о запущенных им процессах, останавливает только свои предыдущие сеансы, дожидается освобождения портов и ведет отдельный лог текущего и предыдущего запуска.
- Данные профилей, настроек, сгенерированной конфигурации, логов, установщиков обновлений и браузерных proxy-профилей хранятся локально в `%LOCALAPPDATA%\OutwardApp`.
- Релизная сборка включает Windows-установщик с упакованным sing-box, SHA256-артефактами, GitHub Actions публикацией и генерацией версионного `release-notes-<version>.md` из этого файла.
