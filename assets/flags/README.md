# Country flags

The two-letter SVG files are the 4:3 flags from
[lipis/flag-icons](https://github.com/lipis/flag-icons), pinned to commit
`ac7e0eb3259eb62aa6100c435607e2fe03896a97`.

These files are distributed under the MIT license; see the accompanying
`LICENSE` for the original copyright and permission notice.

Only the SVG assets are used. No npm package, CSS, CDN or runtime network
requests are required. The complete directory, including attribution, is
bundled by `OutwardApp.spec`.

`unknown.svg` is Outward App's neutral globe for automatic/unknown countries
and missing flag assets.
